# Fixed-wing target asset attribution

## Active Shahed-136 visual

The active visual uses the unmodified Sketchfab glTF download:

- `meshes/shahed_136/scene.gltf`
- `meshes/shahed_136/scene.bin`

This work is based on ["Shahed 136"](https://sketchfab.com/3d-models/shahed-136-bc8754128c9d48c48baadeff1db8f0c7)
by [faintastic](https://sketchfab.com/faintastic), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The attribution
generated by Sketchfab is included as `LICENSE.shahed-136.txt`.

The SDF applies only pose and scale metadata so the visual matches the
3.5 x 2.5 x 0.5 m reference envelope. The downloaded geometry and materials
are not modified.
